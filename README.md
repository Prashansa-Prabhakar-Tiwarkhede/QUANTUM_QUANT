# 🚀 AI for Indian Investor — Investment Intelligence System

## 📌 Overview

*****NOTE*****
We have not added config.py and .env file as it contains api's
*****NOTE*****

This project is an **AI-powered Investment Intelligence Platform** built for the **ET AI Hackathon 2026**.

It transforms raw stock market data into **actionable insights** using a **multi-agent AI system**, helping retail investors make smarter financial decisions.

## 🎯 Problem

Retail investors struggle to:

* Interpret complex stock data
* Identify opportunities
* Make data-driven decisions

Existing platforms provide data, but not **intelligent guidance**.

## 💡 Solution

We built a system that:

* Fetches real-time stock data
* Performs technical analysis
* Predicts trends with confidence scores
* Generates human-like insights using LLMs
* Integrates news and sentiment

👉 Acting as a **personal AI financial advisor**

## ⚙️ Key Features

### 📊 Real-Time Data

* Live stock data using APIs (Yahoo Finance)

### 📈 Technical Analysis

* RSI, MACD, Moving Averages

### 🤖 AI Prediction

* Trend prediction with confidence scoring

### 🧠 LLM Insights

* Human-readable explanations
* Buy/Sell suggestions

### 📰 News & Sentiment

* Real-time news integration

### 📉 Visualization

* Interactive graphs and comparisons

### 🔁 Multi-Agent Architecture

* Data Agent
* Analysis Agent
* Prediction Agent
* Insight Agent

## 🧠 Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Flask (Python)
* **Data APIs:** Yahoo Finance (yfinance)
* **ML & Analysis:** Pandas, TA indicators
* **LLM Integration:** OpenRouter (DeepSeek / GPT models)

## 🏗️ Architecture

The system follows an **Agentic AI workflow**:

1. Data Agent → Fetches stock data
2. Analysis Agent → Applies indicators
3. Prediction Agent → Forecasts trends
4. LLM Agent → Generates insights

All agents collaborate to deliver a **complete decision pipeline**.

* ⏱️ 80% reduction in manual analysis time

* 💡 Faster, smarter investment decisions
